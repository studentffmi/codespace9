CODE SPACE — оновлення лендингу: авторка + підготовка до Google

Готово:
• Замінено assets/author.webp на фотографію, надану авторкою.
• Змінено ЛИШЕ оформлення блоку «Про авторку»: помаранчевий фон, контрастний білий текст, більше фото.
• Збережено дизайн і функції інших блоків: 149 грн, таймер, 12 скриншотів, юридичні сторінки, відео-заглушка, кнопка звернення.
• На всіх п'яти HTML-сторінках залишено/додано індексовані заголовки, описи, метатеги robots. На головній додані структуровані дані LearningResource.

ПЕРЕД ПУБЛІКАЦІЄЮ:
1. У майбутньому окремо додайте відео та посилання WayForPay у SITE_CONFIG (внизу index.html).
2. Розмістіть повний сайт на GitHub Pages (у репозиторії мають бути index.html і папка assets/ поруч).
3. Після публікації зафіксуйте реальну адресу сторінки, наприклад https://ВАШ-ЛОГІН.github.io/НАЗВА-РЕПОЗИТОРІЮ/ .
4. Тільки після цього можна правильно створити sitemap.xml із ПОВНИМИ абсолютними URL сторінок, додати canonical й og:url. Поки адресу не надано, фальшиві URL у цих тегах НЕ вставлялися.
5. Відкрийте Google Search Console → Додати ресурс → Префікс URL. Підтвердіть право власності (HTML-файл або meta-tag) та надішліть sitemap.xml.
6. У Перевірка URL перевірте головну сторінку у реальному часі й надішліть запит на індексацію. Google вирішує, чи й коли включити сторінки до індексу; гарантій немає.

ВАЖЛИВО ДЛЯ GITHUB PAGES: файл robots.txt у підкаталозі /ім'я-репозиторію/ не є доменним /robots.txt. Для подання карти сайту використовуйте Search Console.

Повний архів містить також юридичні сторінки та зображення. Для швидкого оновлення на вже опублікованому сайті достатньо index.html + assets/author.webp.
