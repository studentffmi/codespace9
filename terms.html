Як придбати та використовувати цифровий комплекс CODE SPACE

1. Продавець і предмет оферти

Ці умови є публічною пропозицією щодо придбання цифрового навчального комплексу CODE SPACE — «Галактика Python» для 9 класу. Продавець — ФОП Машкаринець Юлія Віталіївна (РНОКПП 3467001421). Замовляючи продукт, покупець підтверджує ознайомлення з описом, вартістю та умовами його отримання.

2. Опис і комплект

CODE SPACE — автономна HTML-гра з десятьма навчальними секторами на теми одновимірних масивів, списків, сортування, пошуку, рядкових величин і модульних проєктів. До комплексу належать 30 різнорівневих інтерактивних задач, теоретичні пояснення, практичні роботи «Опрацювання списків» та «Опрацювання рядків», п’ять варіантів модульних проєктів, навчальна консоль і матеріали для вчителя.

Навчальний виконавець підтримує лише підмножину команд Python, потрібних у грі; він не є повним інтерпретатором Python. Для виконання довільних Python-програм рекомендовано встановлене середовище Python.

3. Ціна, оформлення замовлення й оплата

Тестова ціна CODE SPACE становить 169 грн за один цифровий комплект. Перед підтвердженням замовлення покупець бачить фактичну суму до сплати; у разі відмінності вона має бути погоджена до платежу. Після підключення платіжної сторінки доступна онлайн-оплата через WayForPay засобами, запропонованими на платіжній сторінці (зокрема банківськими картками та платіжними гаманцями, якщо вони доступні). До підключення оплати оформлення здійснюється через звернення до продавця.

4. Надання цифрового продукту

Після успішної онлайн-оплати та активації автоматичної видачі на електронну пошту покупця має одразу надходити лист із посиланням Google Диска для завантаження ZIP-архіву. Фізична доставка не здійснюється. Територія продажу — Україна; можливість оплати з інших країн залежить від способів, доступних платіжному сервісу.

Якщо автоматичний лист не надійшов після підтвердження платежу, зверніться до продавця за контактами на сайті. Деталі наведено в розділі «Оплата й отримання».
